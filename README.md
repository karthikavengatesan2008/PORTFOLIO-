# Nila Portfolio

## Folder structure
portfolio/
├── index.html
├── css/
│   └── style.css

## How to run
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge/Firefox.
3. Edit your name, email, social links, skills and projects in `index.html`.

Note: The contact form is front-end only. To actually receive messages, connect it to a backend or a form service.
